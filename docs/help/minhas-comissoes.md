# Minhas comissões

Este tópico é exclusivo para barbeiros. Acesse **Despesas e Faturamento** pelo menu para abrir a consulta **Minhas comissões**.

Selecione uma unidade associada, informe as datas inicial e final e escolha **Aplicar período**. O resumo mostra o total de comissões registradas e a quantidade de checkouts considerados. Checkouts antigos sem snapshot de comissão são identificados como incompletos e podem não compor uma estimativa confiável.

Esta tela é individual. Ela não exibe as despesas, os custos, o salário-base nem o lucro da unidade. A comissão é calculada a partir dos atendimentos registrados e da configuração aplicável ao serviço; para dúvidas ou divergências, procure o administrador responsável. Os valores da tela não são comprovantes de pagamento.
