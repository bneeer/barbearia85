# Estoque

Este tópico é exclusivo para administradores. Abra **Estoque** para consultar produtos de venda e insumos utilizados nos serviços.

## Buscar e acompanhar itens

Use a busca por nome e os filtros de tipo e situação para localizar itens. A lista informa quantidade, estoque mínimo e alertas de estoque baixo. Abra um item para conferir seus detalhes e o histórico de movimentações.

## Cadastrar produtos e insumos

Cadastre produtos com nome, marca, descrição, preço de venda e quantidade mínima. Para insumos, informe também unidade de medida (por exemplo, unidade, grama ou mililitro). Se houver saldo inicial, registre a quantidade e o custo total da entrada para estabelecer o custo médio.

Associe os insumos usados aos serviços na configuração do serviço. As quantidades sugeridas no checkout ajudam a equipe a registrar o consumo real.

## Registrar movimentações

Use uma **entrada** quando houver reposição. Informe a quantidade recebida e, quando solicitado, o custo total da compra. Use uma **saída** para uma retirada real e informe o motivo. Use **ajuste** somente para corrigir a quantidade após conferência física, descrevendo o motivo corretamente.

Confira o item, o tipo, a quantidade e o motivo antes de salvar. O histórico registra quem realizou a movimentação e o saldo resultante. O sistema calcula o custo médio ponderado conforme entradas registradas; saldo antigo sem custo conhecido não é considerado gratuito.

Se a quantidade estiver errada ou o sistema indicar estoque insuficiente, confira primeiro o estoque físico e as movimentações. Não crie uma entrada apenas para contornar uma baixa não confirmada.
