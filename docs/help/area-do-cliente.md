# Área do cliente

A área do cliente é uma consulta privada acessada por um link temporário enviado ao e-mail informado na solicitação. Não é uma conta com senha e não permite editar ou cancelar reservas. O link não deve ser encaminhado a outras pessoas.

## Solicitar e abrir o acesso

1. Na página inicial, solicite acesso à área do cliente e informe o e-mail usado nos agendamentos.
2. Abra a mensagem recebida e use o link dentro do prazo de validade (uma hora).
3. Se o link expirou, solicite um novo. Se não encontrar a mensagem, confira spam e se o e-mail corresponde ao informado nas reservas.

O link apresenta informações associadas ao e-mail em todas as unidades. Caso haja cadastros duplicados ou um endereço compartilhado, os dados exibidos podem incluir mais de um registro associado; proteja o acesso como informação pessoal.

## O que é possível consultar

- Próximos agendamentos e histórico, incluindo unidade, serviço, profissional, data, horário e situação.
- Indicadores de atendimentos concluídos, como serviço mais frequente e profissional favorito, quando disponíveis.
- Programa de fidelidade por unidade: saldo de carimbos, progresso e recompensas disponíveis.

Quando o programa de fidelidade estiver pausado, nenhum novo carimbo é concedido até ser reativado pela equipe. As regras e recompensas dependem de cada unidade.

## Alterar uma reserva ou pedir ajuda

O portal é somente para consulta. Para cancelar, use o link de cancelamento enviado para a reserva dentro do prazo indicado. Para reagendar, corrigir dados ou obter ajuda, contate a unidade pelos telefones disponíveis no site.
